ここで動画に切り替え。まなびのライブでの雑談 → 文字起こし → タグ提案・承認 → 打診で部屋が立つ → 知識地図・ライブの種、の順に操作しながら小話を挟む。

個人情報を自動マスク 乗っ取り命令は実行されず タグは管理者承認を必須に 部屋は必ず本人に打診 Named Routerでコスト97.7%減 壊しても安全に停止
