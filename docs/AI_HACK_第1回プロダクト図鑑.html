06🔍 プロダクト個別カルテ

🍼 泣きやみなさいわが子よ 保育 × 感情ケア

延長保育・一時預かりの3〜6歳児の「ママに会いたい」に、保護者の顔と声のAI動画で応えるシステム。AIは親の代替ではなく、現場の大人が寄り添う「きっかけ」を作る。

👥 チーム
3名(人間3名がレビューと意思決定を担当。背景は非公開)
💼 価値
月額原価 約8,600円(直接4,100+管理4,500)に対し 売価9,800円/月 を想定。親子分離不安の軽減+保育士の負担軽減
🛠️ ツール
Node.js / OrcaRouter(STT・安全判定・返答生成) / ElevenLabs(音声クローン) / Tavus Echo + Daily(アバター動画) / AES-256-GCM暗号化
🛡️ 安全設計
safetyLevelを4段階判定(normal→adult_required→urgent→uncertain)。虐待・自傷の訴えでは保護者メディアを停止し大人へ。API失敗時は 映像→写真→テキスト→中立案内 の4段階縮退

ARCHITECTURE

🎤 子どもの音声→STT→👩 大人確認→OrcaRouter 安全判定+返答文→ElevenLabs 音声→Tavus 表情動画

🧓 ツマヅキ UXテスト自動化

AIペルソナで自治体サイト等のユーザビリティを測る。「高齢者らしく演技して」では嘘になるため、理解できる語彙・見える画面範囲を実データで制約して測定。同一サイトで対照群43秒 vs 高齢者ペルソナ2分27秒の差を検出した。

👥 チーム
teamK・2名(背景は非公開。記事はPython/Java/React系タグをフォローするエンジニア)
💼 価値
「使いにくい」という感想を出典付きの数字に変え、改善の優先順位付けを可能に。モデル使い分けでLLM費用89.4%削減($39.98→$4.23)
🛠️ ツール
Playwright(システムChrome操作) / Next.js / Node.js / OrcaRouter / 国立国語研究所「外来語定着度調査」等の公的データ
🤖 モデル分担
画面読取=Gemini flash-lite、次手決定=GPT-5-mini、到達判定=Gemini flash、説明生成=GPT-5-mini (用途×コストで4役に分割)

ARCHITECTURE

observe() 画面把握→shield() 危険入力遮断→constrain() 語彙・視野を制約 ←本体→OrcaRouter 4モデル→Playwright操作

🌡️ CROWD WEATHER イベント安全運営

開催日・天候・チケット販売数から混雑と暑熱(WBGT)の「予報」を作り、会場図に危険箇所を色付けして運営計画書まで自動生成。紙とPowerPointと経験者の勘をデータに置き換える。

👥 チーム
非エンジニア2名:元会計士+元広告代理店のイベントプロデューサー。Codex/Claude Codeと「協働開発」し、企画段階からAIと壁打ち
💼 価値
AI原価を試算で-94%(18,000枚規模で¥116,940→¥7,414)。属人的な運営ノウハウをチームの共有物に。制作/現場/参加者の3画面構成
🛠️ ツール
Next.js(App Router) / React / TypeScript / Vercel / Vitest(331件) / OrcaRouter(GPT-4o読解・Claude Sonnet計画書・Gemini Flash Lite指示)
🧮 設計原則
「AIに計算はさせない」— 混雑指数・WBGT・経路探索は決定的なTypeScript実装。LLMは資料読解と文章生成のみ。計画書配信は人間の明示操作が必須

ARCHITECTURE

📄 非構造資料→LLM層 読解のみ→決定的計算層 混雑・WBGT→🗺️ 会場図の色付け→計画書生成→👩 人間承認→配信

🧑‍🏫 SocraMetry エンジニア育成

エラーを3秒でAIに丸投げする若手から「答えを取り上げる」AIメンター。エラーを投げると修正コードではなくソクラテス式の「問い」が返り、理解の深さを組織の評価データにもする。

👥 チーム
2名。リーダーは組み込みソフトウェアエンジニア(Uhuru所属・enebular/IoTコミュニティで89記事の発信歴)。マネージャーとして若手の課題を目撃したのが着想
💼 価値
月額1,000〜2,000円/人を想定、LLM原価は月39〜55円で粗利十分。SES・派遣のスキルシートに実績の裏付け、過去障害の演習問題化
🛠️ ツール
TypeScript / enebular(クラウド実行環境) / OrcaRouter / GitHub Actions + enebular CLI / enebularデータストア(KVS)
🚪 ゲート設計
Gate A(ヒント)→B(設問)→C(答え開示)が時間経過で自動進行し業務は止めない。診断モデルは出題モデルに「着眼点だけ」を渡し、答えの漏洩を構造的に防ぐ

ARCHITECTURE

🐛 エラー投稿→Diagnoser 高品質モデルで原因特定(1回)→ 着眼点のみ →Questioner 安価モデルで問い生成→Gate A→B→C

💰 Ergarch 共同受託の業務基盤

フリーランス連合・LLPの「案件後の報酬分配交渉」を消す。AIが要件定義を支援し見積工数付きタスクへ自動分解、同じ数字からクライアント見積とメンバー報酬見込みを同時算出。タスク完了と同時に報酬が見える。

👥 チーム
著者はクラウドエンジニア1年目(Azure中心)。学生時代にIBM Champion 2020-21・AWS/Microsoftの学生アンバサダー歴という早熟型
💼 価値
金銭交渉の摩擦を排し「進む過程で分け方が見えている」心理的安全性。実績蓄積でチーム固有の補正係数を継続改善
🛠️ ツール
Next.js 16 / React 19 / TypeScript / Hono / Node.js 22 / Cloud Run / Firestore / Firebase Auth / Vercel AI SDK + OrcaRouter + Zod / Puppeteer(PDF)
🔒 堅牢化
金額計算は共有パッケージの純粋関数に一本化(Web/API同一実装)。工数・単価・承認状態はFirestore Security Rulesで直接変更不可。LLMはモデルIDでなく「用途名」で呼び環境変数で差し替え

ARCHITECTURE

Next.js + Firebase Auth→Hono API on Cloud Run→OrcaRouter → 各LLM/Firestore リアルタイム購読/Puppeteer → PDF

🗂️ KYAKUMAP 法人営業の訪問準備

日報・商談メモ・議事録に散らばる顧客情報をつなぎ、「チームが何を知らないか」の境界を可視化する営業準備AI。関係者マップと5領域の情報充足度、根拠付きの質問応答を提供。

👥 チーム
個人開発。Javaメイン(+Kotlin/React)のエンジニアで、営業経験者へのユーザーインタビューから課題を発掘。普段は初心者向け記事を書く発信者
💼 価値
準備の質が成約速度に直結(できる担当者は1〜2ヶ月、できない担当者は半年〜1年)。CRMの置き換えではなく既存記録の横断活用に特化
🛠️ ツール
Next.js / PostgreSQL / Drizzle ORM / OrcaRouter(マルチLLM+音声API) / Notion API連携
🛡️ 3層防御
①質問対象の周辺データのみLLMへ ②OrcaRouter Guardrailsでメール・電話マスク、APIキー等はブロック ③LLMが返す根拠ID・人物IDをDBの許可リストで再照合

ARCHITECTURE

📚 日報・議事録・Notion→PostgreSQL 知識はDB→OrcaRouter 表現はLLM→サーバーで根拠ID検証→🗺️ 関係者マップ+充足度

🔁 pakulist SNS運用・権利保全

SNSの重複・類似投稿(パクリ投稿)を検出し、断定せずに「人が判断できる候補と根拠」(投稿URL・時刻・本文・判定方法・時間差)へ整理するWebアプリ。

👥 チーム
2名(@tmyymmt + @rkyymmt)。tmyymmt氏はパーソルクロステクノロジー所属、Scala/Ubuntu系のエンジニアで技術書レビュー等も発信
💼 価値
目視比較の時間を削減しつつ、権利・料金・責任分界を先に設計して「何を今は実装しないか」を成果物に。誤断定リスクをAIに負わせない
🛠️ ツール
HTML/CSS/JS / Node.js 22(静的サーバー) / 検出は正規化・トークン類似度・時系列比較の決定的実装 / node:test + Playwright + 性能ベンチ / OrcaRouterは将来接続
📐 特徴
唯一の「AIをまだ入れない」設計。ローカル処理優先で、実データ送信は導入ゲート確認後に限定。APIキーはブラウザから分離した最小サーバーに隔離

ARCHITECTURE

CSV / JSON / X API形式→検出層 完全一致・近似・時系列→画面 / CSV / HTML証拠パッケージ⋯AI層(将来・分離API)

🚶 Routeoff ライフログ × 行動変容

気分と過去の記録から日常を小さく外れる「寄り道」を提案し、撮った一枚から観察候補を抽出、週次の振り返りへ循環させるアプリ。「何もできなかった」という後悔を減らす。

👥 チーム
teamR。著者は日本オラクルのクラウドエンジニア(OCI記事84%、Claude Code/Codex活用のスキル自作経験あり)
💼 価値
学生層がターゲット。記録を公開競争でなく「自分だけの根拠」として保存する差別化。週次視点→次の寄り道の循環設計
🛠️ ツール
HTML/CSS/JS + Node.js / OrcaRouter(提案・写真解析・週次生成の3用途) / Claude Codeでセキュリティレビュー、Codex併用 / 将来はOKE + Autonomous AI Database + Object Storage + Vault
🛡️ 工夫
画像はブラウザ側で最大1400pxに再圧縮してから送信。用途ごとにJSONで受け、必須項目・文字数・根拠IDをサーバー検証。失敗時は固定文へフォールバック

ARCHITECTURE

📷 写真+気分入力→ブラウザで画像圧縮→Node.js API→OrcaRouter 3用途→JSON検証→📅 週次振り返り
