柱
門1｜タグ辞書 — 出力を辞書からの選択に縛る。任意の文字列を書き込めない＝構造そのものが防御になる

A

A
自己申告だけではラベルにしない。他人に答えた実績を重みにする
B
Agent Firewall（egress）。打診文も出口で検査する
B
打診回数のハードリミット ＋ 通知の1日あたり総量上限
B
スコープ付きAPIキー（予算上限・有効期限）＝暴走時の被害に天井がある
