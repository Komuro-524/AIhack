# 記事用スクリーンショットの撮影手順

## 🗺️ 全体の流れ

1. Supabase の SQL Editor で SQL を流す（下の「準備」）
2. アプリを起動する（`npm run build` → `npm run start` → http://localhost:3030）
3. ログイン画面の **架空社員のボタン** で人を切り替えながら撮る
4. 画面で何か押して状態が変わったら `reset-demo.sql` をもう一度流す

## ① 準備（SQL Editor で上から順に Run）

| 順番 | ファイル | 何が入るか | すでに流していたら |
|---|---|---|---|
| 1 | `supabase/migrations/0020_tag_requests.sql` | 「タグにしてほしい」申請のしくみ | もう一度流しても壊れない |
| 2 | `supabase/migrations/0021_ui_demo_seed.sql` | タグ帳の札・ライブのタネ5つ・打診 | もう一度流しても増えない |
| 3 | `supabase/demo/reset-demo.sql` | 全部を「デモの最初の状態」に戻し、配信中のライブを1つ立てる | 撮影のたびに流してよい |
| 4 | `AIhack/docs/article-shots/article-shots.sql` | 配信中のライブの発言とリスナー・知識地図用のカード・藤代さんの非公開タグ | もう一度流しても増えない |

| 話した言葉 | 配信中の参加者 | 地図用のカード | 藤代さんの非公開タグ |
|---|---|---|---|
| 6 | 7 | 12 | 2 |

※ 1〜4 はこちらの手元（Postgres互換のテスト環境）で同じ順に流して、上の数字になることを確認済み

## ③ タグ帳のGIFの撮り方（#6）

1. Windows の **Snipping Tool** を開き、「録画」で画面の一部を囲む
2. タグ帳を開く → 札を1枚クリックして **めくる** → 別の札を引っぱって **破る**
3. 録画を止めて mp4 を保存する
4. GIF に変換する（ScreenToGif などのツール。**5秒前後・幅800px程度** に縮めると軽い）
5. 撮り終えたら `reset-demo.sql` を流して札を戻す

## ④ 自己分析を実際に動かす（#3 の結果パネルを撮りたいとき）

1. `AIhack/docs/mirror-shots/2026年9月_備品発注集計.xlsx` を Excel で開いておく
2. 藤代 咲良でログイン → 自己分析 → 時間を短め（1分）にして開始
3. 共有のダイアログで **Excel のウィンドウだけ** を選ぶ（画面全体は選ばない）
4. 1分のあいだ、ピボットやグラフを少し触る
5. 終わったら結果パネルとプロフィールを撮る

⚠️ デスクトップ・タスクバー・ブラウザのブックマークバーが写らないようにする（自分の開発環境の跡が映り込むため）
💰 実際にOrcaRouterを呼ぶので、1回あたり1円未満の費用がかかる
